\# Project Setup Guide



\## Prerequisites

\- Python 3.8 or above

\- Git 2.x



\## Installation Steps



1\. Clone the repository:

&#x20;  `git clone <repo-url>`



2\. Open the project folder:

&#x20;  `cd cse103-lab-LAB3`



3\. Run the Python program:.   `python3 src/main.py`



\## Project Structure

The project is organised into `src`, `tests`, and `docs` folders.
